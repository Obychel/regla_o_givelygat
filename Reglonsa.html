Обзор Конланга "Regla o Givelygat"

Этот документ описывает алфавит, фонетику, основные грамматические особенности, лексику искусственного языка "Regla o Givelygat".

0. Алфавит и Фонетика

Язык использует латинский алфавит со следующими особенностями:

  • Состав Алфавита: Отсутствуют буквы b, h, p, q.
  • Гласные: y произносится как [ʉ]. Дифтонги отсутствуют.
  • Согласные: c — [t͡s], g — [ɣ], j — [j]. Единственный звонкий взрывной — d [d].
  • Аллофония:
    • n /n/ → [ŋ] /_k; [ɰ̃] /g
    • m /m/ → [ɱ/m̪] /{f, v}
    • v /v/ → [β̞] /V_C
  • Фонотактика и палатализация:
    • tj [tɕ]
    • sj [ɕ]
    • xj [kɕ]
    • dj [dʑ]
    • zj [ʑ]
  • Ударение: Произвольное, с тенденцией падения на слог перед окончанием.
  • Фонотактика: Не более 2 согласных в стечении. Запрещены стечения типа "носовой/сонорный + фрикативный/взрывной" в начале слов.
  • Адаптация заимствованных слов под фонетику этого языка:
    • b / w → v
    • p → f
    • h → g
    • q → k
    • Vo → Vwo
    • Vu → Vw / Vwu

1. Ключевой Принцип: Гармония Аффиксов

Основа морфологии — правило чередования гласных и согласных на стыке морфем:

  • К основе на согласный → аффикс на гласный.
  • К основе на гласный → аффикс на согласный.

2. Морфология

Типологически морфология языка Regla o Givelygat агглютинативная с элементами аналитизма.

  • Черта агглютинативной морфологии: Способность основ принимать суффиксы ВНЗА для образования глагольных основ, а затем к глагольным или неглагольным основам добавляться терминальные окончания для образования конкретных частей речи.
  • Черта аналитизма: Выражение многих грамматических значений (род, реальность/абстрактность, степени сравнения, отрицание) с помощью служебных слов или конструкций.

2.1. Виды Основ и Образование Частей Речи

Существует два вида основ:

  1. Неглагольная (Первичная/Обычная) Основа (ОО): Используется для образования именных частей речи, наречий и прилагательных напрямую.
    • Может быть корнем (который сам по себе является ОО).
    • Может образовываться от корня или другой ОО с помощью деривационных суффиксов или деривационных приставок:
      • Суффикс инструмента: -ll- (после гласного), -orl- (после согласного).
        Примеры:
        • tavalla (сущ. печь) = tava- + -ll- + -a (как инструмент действия, противопоставляется tavas — сущ. хлеб = tava- + -s, результат действия);
        • deflorl- (основа сущ. мир, вселенная; прил. мировой, вселенский) = defl- + -orl-;
        • fonorl- (основа гл. зажигать, сущ. зажигалка);
        • fijorl- (основа гл. включать технику, сущ. техника);
        • alella (сущ. свет, лампа);
        • fevull- (основа сущ. семя, сперма; гл. формировать семя, изливать семя);
        • ivoll- (основа сущ. половой орган, гл.перех. сношать);
        • rojilla (сущ. ёмкость для сбора, мешок);
        • jadorla (сущ. задница);
        • galulla (сущ. грудь);
        • jerell- (основа сущ. круг, гл. закруглять(ся));
        • loforla (сущ. физ. материя);
        • mynella (сущ. нос).
      • Суффикс профессии: -ler- (после гласного), -ajo- (после согласного).
      • Суффикс совместности: -nyk-/-ng- (после гласного), -elo- (после согласного).
      • Суффикс принадлежности: -no...- (после гласного), -on...- (после согласного). Возник из предлога on и имеет формы:
        • После гласного: 1sg: -nos-, 1pl (ex): -nost-, 1pl (in): -nosm-, 2sg: -nor-, 2pl: -nors-, 3sg: -gos-, 3pl: -got-.
        • После согласного: 1sg: -ons-, 1pl (ex): -ont-, 1pl (in): -omm-, 2sg: -onr-, 2pl: -onzi-, 3sg: -ogs-/-ox-, 3pl: -ogtu-/-oktu-.
      • Приставка противоположности смысла: mi- (для основ с согласной) / mij- (для основ с гласной).
        Примеры: nidar (прил. простой) → minidar (прил. сложный); mer- (жить/жизнь) → mimer- (умирать/смерть); fijorl- (включать технику) → mifijorl- (выключать технику); mijali- (терять сознание); mic- (отсутствовать); mivis- (заканчивать); mijorv- (раскрывать / to discover); misamr- (тихий/тишина).
  2. Глагольная Основа (ГО): Образуется добавлением суффикса ВНЗА к любой другой основе (корню, ОО). Используется для образования финитных глаголов, имен действия, причастий, деепричастий.

    Когда ГО произведена из ОО, обозначающей признак, для отличия действия состояния и действия увеличения свойства признака используются разные конструкции:

    • d- + сущ./прил. от ОО (действие состояния)
    • гл./прич./деепр. от ГО (действие прогрессии признака)

Морфология Основных Частей Речи:

  • Существительное (+ местоимение, числительное): ОО + Окончание_ЧПТР_Сущ
  • Прилагательное: ОО + Окончание_ЧПТР_Опред
  • Наречие: ОО + Окончание_Обст (-ov / -go)
  • Глагол (финитный): ГО + Окончание_ЭЛЧ
    • Глагол d- (быть) — исключение: Урезанный суффикс времени, без залога + Окончание_ЭЛЧ (начальное da- выпало). Исторические примеры: *danajs → najs, *darejko → rejko, *dakart → kart, *dadara → dara, *dajysi → jysi, dane(l) → ne(l) (являющийся), dano → no (являясь).
  • Имя Действия: ГО + Окончание_ЧПТР_Сущ
  • Причастие: ГО + Окончание_ЧПТР_Опред
  • Деепричастие: ГО + Окончание_Обст (-ov / -go)
  • Предлоги, Частицы, Союзы: Имеют простую, одноморфемную форму.

А. Вербализация (Создание Глагольной Основы): Суффиксы ВНЗА

Преобразует любую основу в Глагольную Основу (ГО).

Суффиксы Времени/Наклонения/Залога/Аспекта (ВНЗА):

  • Несовершенный аспект:
    • Для основ на согласный (требуют суффикс на гласный):
      • Наст. Индикатив: Актив -en-, Рефлексив -an-, Пассив -in-, Взаимный -un-.
      • Прош. Индикатив: Актив -er-, Рефлексив -ar-, Пассив -ir-, Взаимный -ur-.
      • Буд. Индикатив: Актив -ek-, Рефлексив -ak-, Пассив -ik-, Взаимный -uk-.
      • Императив: Актив -ed-, Рефлексив -ad-, Пассив -id-, Взаимный -ud-.
      • Атемп. (Общее время): Актив -ej-, Рефлексив -aj-, Пассив -ij-, Взаимный -uj-.

      • Наст. Индикатив: Актив -ne-, Рефлексив -na-, Пассив -ni-, Взаимный -nu-.
      • Прош. Индикатив: Актив -re-, Рефлексив -ra-, Пассив -ri-, Взаимный -ru-.
      • Буд. Индикатив: Актив -ke-, Рефлексив -ka-, Пассив -ki-, Взаимный -ku-.
      • Императив: Актив -de-, Рефлексив -da-, Пассив -di-, Взаимный -du-.
      • Атемп. (Общее время): Актив -je-, Рефлексив -ja-, Пассив -ji-, Взаимный -ju-.
  • Совершенный аспект:
    • Для основ на согласный (требуют суффикс на гласный):
      • Прош. Индикатив: Актив -evr-, Рефлексив -avr-, Пассив -ivr-, Взаимный -uvr-.
      • Буд. Индикатив: Актив -evk-, Рефлексив -avk-, Пассив -ivk-, Взаимный -uvk-.
      • Императив: Актив -evd-, Рефлексив -avd-, Пассив -ivd-, Взаимный -uvd-.
      • Атемп. (Общее время): Актив -ev-, Рефлексив -av-, Пассив -iv-, Взаимный -uv-.
    • Для основ на гласный (требуют суффикс на согласный):
      • Прош. Индикатив: Актив -rve-, Рефлексив -rva-, Пассив -rvi-, Взаимный -rvu-.
      • Буд. Индикатив: Актив -kve-, Рефлексив -kva-, Пассив -kvi-, Взаимный -kvu-.
      • Императив: Актив -dve-, Рефлексив -dva-, Пассив -dvi-, Взаимный -dvu-.
      • Атемп. (Общее время): Актив -ve-, Рефлексив -va-, Пассив -vi-, Взаимный -vu-.

Залоги:

  • Значение залогов для переходных глаголов:
    • Актив: действие субъекта на внешний объект (yn).
    • Рефлексив: действие субъекта на самого себя.
    • Пассив: действие извне на субъект; агенс маркируется предлогом gyl.
    • Взаимный: действие двух субъектов друг на друга.
  • Особенности залога для непереходных действий:
    • Рефлексив: стандартный залог для простого действия ("идти").
    • Актив: придаёт значение принуждения (заставлять идти).

К основе (ОО или ГО) присоединяется одно терминальное окончание.

Г. Наречия и Деепричастия

ОО (для нареч.) или ГО (для деепр.) + обстоятельственное окончание (-ov / -go)

Пример пошагового построения слова: "знающий, вообще"
  • Шаг 1 (Создание ГО): lare- (ОО, идея: знать) + -je- (суффикс ВНЗА, Атемп.Актив) → lareje- (ГО, "знать (вообще)").
  • Шаг 2 (Образование Причастия): lareje- (ГО) + -r (окончание ЧПТР_Опред, I скл. ед.ч. рема) → larejer ("знающий, вообще").

3. Синтаксис

  • Порядок слов: Базовый S dO V iO, где dO — direct object (прямое дополнение) с предлогом yn, iO — indirect object (непрямое дополнение) с предлогами, кроме yn. Внутри фраз: Head-Modifier.
  • Валентность глаголов:
    • Непереходные/одновалентные глаголы (fyla- 'ұйықтау') могут быть соединены лишь с подлежащим.
    • Однопереходные/двухвалентные глаголы (okaj- 'создавать') управляют прямым объектом (yn).
    • Двухпереходные/трёхвалентные глаголы (iraj- 'давать') управляют прямым объектом (yn) и непрямым объектом-получателем (re) или непрямым объектом-исходником (ly/l').
    • Непереходный, одно- или двухвалентные глаголы d- (быть) и s- (не быть) слева от себя соединены с подлежащим, справа — с именной частью сказуемого (предикативом) тоже в именительном падеже.

3.1. Сложноподчинённые предложения

Относительные придаточные ("который") отсутствуют; их смысл передаётся через другие обороты (напр. причастные).

  • Причина ("потому что"): mir + имя действия (рема). Субъект имени действия маркируется предлогом o/on.
    Пример: mir regelevra on osa yn dus dyl lal (потому что я поставил это туда; букв. "из-за моей постановки этого туда").
  • Цель ("чтобы"): fi / f' + имя действия в атемпоральном времени.
    Пример: fi larejes on ara (чтобы ты знал; букв. "для твоего знания").
  • Намерение (собираться что-то сделать): gal- (идти к цели) + dyl + имя действия в атемпоральном времени.
    Пример: galanejki dyl vajaval (слышал, они собираются прийти; букв. "идут (они по слухам) на приход").
  • Следствие ("так что"): mir + имя действия (тема). Конструкция почти та же, что у причины.
  • Уступка ("хотя"): деепричастие togeno (имея) + имя действия в аккузативе (yn).
    Пример: genyrvexa togeno yn larenezi (он спросил, хотя знал; букв. "(он) спросил, имея знание").
  • Принуждение (Каузатив): Предпочтительно использовать Активный залог для непереходных глаголов. Или: lene- (делать) + yn + имя действия в атемпоральном времени + o/on + именное слово в им.падеже.
    Пример: gityjare so re leneves yn jonifeja on osa yn ges — ты не можешь (вообще) заставить меня любить его.
  • Условие ("если"):
    1. Аналитически: son + имя действия.
      Пример: nadakezy son genykeze on ara (буду отвечать, если будешь спрашивать).
    2. Синтетически: Глагол в условной части принимает специальные окончания условности вместо ЭЛЧ.
      Пример: genykerali, nadakezy (если будешь спрашивать, буду отвечать).

3.2. Степени сравнения и прагматика

  • Степени сравнения (Аналитические):
    • Сравнительная степень (+): [Определение] + gax + ja/j' + [Сравниваемое слово] (опционально).
      Пример: danoj re rogari gax ja lal (является более красным чем то).
    • Сравнительная степень (-): [Определение] + lez + ja/j' + [Сравниваемое слово] (опционально).
      Пример: danaje roganu lez (являются менее красными).
    • Превосходная степень ("самый...", "наиболее..."): [Определение] + rydo ("предельно").
      Пример: rogar rydo (самый/наиболее красный). Отрицание с разным акцентом: sane rogar rydo (наименее красный) против rogar rydo so (не самый красный).
  • Вежливость: Грамматические различия отсутствуют.
  • Формальность: Выражается через выбор более сложных синтаксических конструкций.
  • Усилительная частица: ka (аналог "же", "ведь") ставится после слова, на которое делается акцент.

4. Отрицание

  • Просторечный регистр (после действий): [Положительная форма] + so (s- + -o). Акцентирует отсутствие какого-либо действия.
    Пример: larejerto so (полагаю, ты не знаешь).
  • Разговорный регистр (после имени или признака): sane/sare/sake + [Положительная форма] (sane=s-+-an-+-e, sare=s-+-ar-+-e, sake=s-+-ak-+-e). Выступает в роли определения.
    Пример: sanel roga (некрасный), sane dronal (не камень).
  • Высокий / Приукрашенный регистр (предикат): [Форма от s- в настоящем времени] + [Причастный оборот]. Положительный предикат становится причастным оборотом.
    Пример: sanoj larekveri (он не узнает; букв. "он не станет знающим"), sanoj rogari (он — не красный).
  • Определяющее местоимение "никакой/ая/ое": s- + окончание ЧПТР_Опред.
    Пример: se (никакой, ед.ч. рема).

5. Числительные

  • Базовые корни: Nyl- (0), Est- (1), Lar- (2), Gid- (3), Nav- (4), Mir- (5), Av- (6), Vyz- (7), Sed- (8), Ig- (9), Lam- (10).
  • Суффиксы-множители и суффиксы-прибавлятели: -elmor-/-elm- (+10), -ard- (×10), -eg- (×100), -ynd- (×1000).
  • Крупные числа: Ciz- (10 000), Miljon- (1 000 000).
  • Суффиксы степени (104n): -ol-.
    Примеры:
    • estola jon ciza norujaje — 10000 (синоним 1) и 10000 (синоним 2) равняются друг другу;
    • cizola joj ulel gaxo — 1040000 это очень много;
    • larardola mirolel — 104×20 × 104×5 = 10100 (гугол).
  • Составные числительные: Строятся по схеме [форма от ГО разряда_1] + [форма от ОО разряда_2] + [форма от ОО разряда_3] + .... Десятки, сотни, тысячи выражаются синтетически, а крупные разряды (кратные 4) — аналитически через квантитативно-именные конструкции.
    Примеры:
    • 173 (тема): Gidaja vyzelmarda (gid-aj-a + vyz-elm-ard-a)
    • 101010 (рема): lamajal estynda ciza lame (lam-aj-al + est-ynd-a + ciz-a + lam-e)
  • Количественные числительные:
    • Если определяет количество разряда, не кратного 4: Основа + (суффикс возвратного залога ВНЗА) + окончание ЧПТР_Опред.
    • Если определяет количество разряда, кратного 4: Основа + окончание ЧПТР_Опред.
    Пример: Drona estelmajel estelmege cize estelme estelmege (11111111 камень, рема).
  • Порядковые числительные: Основа числительного + (суффикс пассивного залога ВНЗА) + окончание ЧПТР_Опред.
    Пример: 91-ый (рема): Estijel igarde (Est-ij-el + ig-ard-e).
  • Числительные наречия:
    • Числовая основа + -an- + -o → значение n раз. Пример: vyzano (семь раз).
    • Числовая основа + -in- + -o → значение каждый n-ный раз. Пример: mirino (каждый пятый раз).

6. Местоимения и Частицы

6.1. Местоимения

  • Личные местоимения (форма темы):
    • 1sg: Osa [os-a] (я)
    • 2sg: Ara [ar-a] (ты)
    • 3sg: Ges [ge-s] (он/она/оно)
    • 1pl (ex): Osut [os-ut] (мы эксклюзив)
    • 1pl (in): Osima [osim-a] (мы инклюзив)
    • 2pl: Arus [ar-us] (вы)
    • 3pl: Gek [ge-k] (они)
  • Указательные местоимения:
    • Определяемые: Dus (это), Dojga (эти), La (тот/та/то), Fija (сам).
    • Определяющие: Dur (этот/эта/это), Dojge (эти), Le (то), Fije (сам).
  • Вопросительные: reg- (что/какой), напр. regal (что?), vika regel (когда?), jova regel (сколько? / исчесл.), gila regel (сколько? / неисчесл.).
  • Определяющие местоимения: ade (какой-то), sel (никакой), ivim (какой-нибудь), dore (любой), rum (каждый/весь), nar (кое-какой).

6.2. Частицы, союзы

Tejo (тоже), Liga (только), Jon (и), Ver (или), Mil (но), Liro (тогда), Migo (почти/чуть не), Emo (даже).

8. Уточнения и Примеры

  • Реальность/Абстрактность (Аналитические):
    • uva drone = "каменность" (качественное существительное).
    • drona gere = "мысленный камень" (абстрактное существительное).
  • Объектное псевдо-деепричастие:

    Конструкция: ОО + императивная форма суффикса ВНЗА + обстоятельственное окончание (напр. ОО + -ed-/-de- + -ov/-go).

    Семантика: идентичен по смыслу имени действия в позиции прямого дополнения.

    Пример: visevra lenedego («начать делать») = visevra yn lenejes.
  • Название языка:

    Regla o Givelygat = Regl- (речь) + -a (сущ. ЧПТР, II скл. ед.ч. тема) + o (принадлежность) + Gively- (этноним/место) + -gat (сущ. ЧПТР, III скл. общ.ч. тема) — "Язык народа/места Гивелю".

  • Развитие послелоговой клитики -du:

    -du, как универсальный знак аккузатива, развился по аналогии из «объектного псевдо-деепричастия», образованного из ОО, оканчивающейся на согласный, так как оно всегда имеет конечное -d-ov [dɒw] вне зависимости от залога. Впоследствии -d-ov трансформировалось в [du] (напр. defladov → defladu), и по этой аналогии -du распространилось на все части речи, которые могут иметь форму аккузатива.

    Оно стало клитикой, присоединяемой через дефис после окончания слова, почти вытеснив архаичный предлог yn (оставшийся в книжной речи). Из-за созвучия с аккузативом существительного (defla-du) старая форма defladu перестала быть продуктивной, оставив архаичное defladov и новую конструкцию deflana-du.
